# С чистого листа

Учебный проект по вёрстке из курса фронтенд-разработки Яндекс Практикума. Самостоятельная реализация готового кейса «С чистого листа» по материалам курса.

Проект выполнен на HTML и CSS без JavaScript, сторонних библиотек и инструментов сборки.

## Технологии

- HTML5.
- CSS3.
- Локальные шрифты Inter и EB Garamond.
- Изображения в форматах SVG и PNG.

## Просмотр проекта

Устанавливать зависимости и запускать сборку не требуется.

### Скачать ZIP-архив

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `index.html` в браузере.

### Клонировать репозиторий

```bash
git clone [https://github.com/V0000DY/s-chistogo-lista.git](https://github.com/V0000DY/s-chistogo-lista.git)
```

После клонирования откройте папку `s-chistogo-lista` в файловом менеджере и запустите `index.html` в браузере.

Для корректного отображения страницы сохраняйте расположение файлов и папок: `index.html` использует стили, шрифты и изображения из соседних каталогов.

## Структура проекта

```text
s-chistogo-lista/
├── .github/          # Служебные файлы GitHub
├── fonts/            # Файлы шрифтов и CSS для их подключения
│   └── fonts.css
├── images/           # Изображения и логотип
├── styles/           # Стили страницы
│   └── style.css
├── index.html        # Разметка страницы
└── README.md         # Описание проекта
```
